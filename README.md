# C++ Practice Projects

A collection of small C++ programs created to practice fundamental programming concepts, including input handling, conditional logic, loops, functions, and basic game development.

## Projects

### Number Guessing Game
A console-based game where the player tries to guess a randomly selected number.

**File:** `C++_Num_guessing_game.cpp`

### Decision Exercise
A small program practicing decision-making and conditional statements in C++.

**File:** `decision_ex1.cpp`

### Main Program
An additional C++ practice program exploring core programming concepts.

**File:** `main.cpp`

## Build and Run

This project uses CMake.

```bash
cmake -S . -B build
cmake --build build
```

Run the generated executable from the `build` directory.

## Topics Practiced
- C++ fundamentals
- Conditional statements
- Loops
- Functions
- Random number generation
- Console input and output
- CMake project setup
